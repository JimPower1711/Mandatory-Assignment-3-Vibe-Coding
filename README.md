# Wealth Tracker

Wealth Tracker er en personlig økonomi-app som hjelper brukeren med å holde oversikt over inntekter, utgifter og sparemål. Appen er laget som en prototype til en universitetsoppgave om generativ AI og Vibe Coding.

## Demo

[Se appen på VibeOff](LIM-INN-VIBEOFF-LENKEN-HER)

## Kildekode

[GitHub-repository](https://github.com/JimPower1711/Mandatory-Assignment-3-Vibe-Coding)

## Funksjoner

- Legge til, redigere og slette inntekter og utgifter
- Søke og filtrere transaksjoner
- Opprette sparemål og registrere innskudd eller uttak
- Se økonomiske oversikter og diagrammer
- Lagre data lokalt i nettleseren med `localStorage`
- Bruke appen på både mobil og desktop

## Teknologi

Appen er bygget med React, TypeScript, Vite, Tailwind CSS og Recharts.

## Bruk av AI

Generativ AI ble brukt til idéutvikling, planlegging, generering av kode, feilsøking og forbedring av designet. Appen ble utviklet trinnvis, og forslag fra AI ble kontrollert og justert underveis.

## Testing

Følgende funksjoner ble testet under utviklingen:

- Oppretting, redigering og sletting av transaksjoner
- Søk og filtrering
- Oppretting og redigering av sparemål
- Innskudd og uttak fra sparemål
- Lagring av data etter oppdatering av siden
- Responsivt design på mobil og desktop
- Produksjonsbygg med `npm run build`

## Kjør lokalt

Du trenger Node.js 20.19+ (20.x) eller Node.js 22.12+.

```bash
npm install
npm run dev
```

Åpne deretter adressen som vises i terminalen.

All økonomisk informasjon i appen er fiktiv. Appen bruker ingen ekte bankdata, personopplysninger eller API-nøkler.
