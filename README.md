# Wealth Tracker

A modern, local-first personal finance dashboard built for a university Generative AI / Vibe Coding assignment.

## Implemented

- React, TypeScript and Vite project foundation
- Tailwind CSS styling
- Responsive desktop sidebar and mobile navigation
- Data-driven dashboard with Recharts visualizations
- Realistic fictional NOK transactions and savings goals
- Automatic localStorage initialization and persistence
- Full transaction management: add, edit, delete, search and filter
- Live dashboard updates after transaction changes
- Savings goal management: create, edit and delete goals
- Contributions, withdrawals and savings activity history
- Live dashboard updates after savings changes
- Period-based analytics for cash flow, spending and savings activity
- Data-derived category breakdowns, financial insights and monthly summaries

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Data and privacy

The application uses fictional demo data and stores it only in the browser. It has no backend, authentication, paid APIs or banking integrations.
